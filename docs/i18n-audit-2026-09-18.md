# 웹 i18n 점검 — 2026-09-18

관찰 시각: 2026-09-18 11:35 KST. 범위는 OpenStoa 웹이며 모바일 패키지는 제외했다. `src/app`, `src/components`의 TSX 71개를 대상으로 JSX 문구, 접근성 이름, 문자열 조건식, 오류 표시, 날짜·숫자 포맷과 번역 호출을 점검했다. Docs 본문 및 프로필 배지 공개 설정은 같은 작업의 별도 변경으로 처리했다.

## 수정한 누락

- 메인 로그인 화면에 로그인 절차를 열지 않고 접근할 수 있는 `/docs` 링크를 추가했다. 한국어에서는 `문서`로 표시한다. 베타 신청의 `Both`, 로그인 데모 상태, 닫기 버튼의 접근성 이름도 번역했다.
- 게시물 상세의 돌아가기, 고정·해제, 삭제 확인, 저장·삭제·댓글 진행 상태, 삭제된 댓글, 댓글 수, 투표 선택지 잠금 안내와 로컬 오류 문구를 번역했다.
- 공통 게시물 작업의 온체인 기록 확인·진행·완료, 삭제 확인, 북마크 접근성 이름, 미가입자의 투표 안내를 번역했다. 피드와 투표의 로컬 실패 문구도 정리했다.
- API가 보내는 정규 배지 라벨 `KYC`, `Country`, `Org`, `OIDC`가 화면 번역을 덮어쓰던 문제를 수정했다. 호출자가 의도적으로 지정한 별도 라벨, 공개 도메인, 국가 코드 및 알 수 없는 표시 값은 보존한다. 이후 같은 날 사용자의 표시 범위 요청에 따라 토픽별 배지 필터를 제거했다.
- 기본 카테고리 8개의 이름을 사이드바, 토픽 생성, 토픽 탐색에서 번역했다. 사용자 정의 카테고리는 원래 이름을 유지한다.
- AI 에이전트 설정의 권한 이름, 기록 범위, 이름 유효성 검사와 날짜를 현재 언어에 맞췄다. 알 수 없는 권한 경로는 원문을 보존한다.
- 온체인 기록 날짜, 편집기 숫자 포맷, 투표 마감까지의 시간 단위, 복구 화면과 게시물 경로의 기본 표시 문구를 정리했다.

## 남은 범위와 의도적으로 유지한 원문

- `/api-reference`의 Scalar CDN UI, OpenAPI 스키마 설명, 기계용 `AGENTS.md`·`skill.md`와 CLI/API 예시는 이번 웹 본문 번역 범위에 포함하지 않았다. 명령어, 옵션, 환경 변수, JSON 키, URL, 제품명, 표준 약어는 그대로 유지한다.
- 비활성화된 `/ask`의 조기 반환 뒤에 있는 이전 채팅 UI에는 영어 문구가 남아 있다. 현재 노출되는 비활성 안내는 번역되어 있다. 기능을 다시 켤 때 이전 UI도 점검해야 한다.
- 루트 metadata, Open Graph/Twitter 설명, JSON-LD와 `pageMetadata.ts`의 기본 설명에는 영어가 남아 있다. 사용자 작성 제목·본문은 번역하지 않는다. metadata는 별도 서버 생성 경로와 공개 정보 노출 규칙이 있으므로 이번 본문 수정에서 변경하지 않았다.
- 서버가 임의의 영어 오류 문자열을 반환하고 클라이언트가 이를 직접 표시하는 경로는 남아 있다. 이번 변경은 확인된 클라이언트 문구와 알려진 로컬 오류를 처리했으며, 전체 API 오류 코드·다국어 메시지 계약을 도입하지 않았다.
- 사용자 작성 내용, 조직 도메인, 국가 코드, 사용자 정의 라벨과 카테고리에는 원래 언어가 유지된다.

이 점검 결과는 “영어가 전혀 없다”는 의미가 아니다. 실제 웹 UI에서 확인된 번역 누락과 서버 배지 라벨의 덮어쓰기를 수정하고, 제외한 경로와 남은 계약 문제를 명시한 결과다.

## 함께 적용한 배지 설정과 통합 검증

- 웹 `/my` 설정과 모바일 프로필에 KYC·국가·워크스페이스·로그인 인증별 표시 설정을 추가했다. 인증 완료 후 기본 ON이며 기존 명시적 OFF와 재인증 후 OFF를 유지한다. 숨기기는 인증 유효성이나 가입 자격을 없애지 않는다.
- 공개 배지는 토픽의 증명 조건과 무관하게 사용자 프로필 이미지·닉네임 옆에 표시된다. 일반 토픽과 로그인 인증 배지도 포함한다. 각 배지의 OFF와 인증 만료만 공개 표시를 제한한다.
- 본인용 API에는 숨긴 배지도 설정을 위해 포함된다. AI 키는 읽기에 `profile/read`, 변경에 `profile/edit` 권한이 필요하다.

## 공개 배지 표시 범위와 프로필 모듈 보완

- 증명 조건별 배지 필터를 제거했다. 로그인 인증을 포함한 모든 공개 배지는 일반 토픽에서도 다른 사람에게 표시한다. 토픽 증명 조건은 가입 자격을 결정하며 배지 표시 종류를 제한하지 않는다.
- 웹은 `UserIdentity`와 `UserBadges`로 사진·닉네임·배지 표시를 통합하고 기존 `UserCard` 팝업을 재사용한다. 모바일도 공통 `UserIdentity`를 사용하며 `PeerProfileCard`에서 재사용한다. 사진 업로드·변경 버튼은 별도 편집 컨트롤로 유지한다.
- 피드, 게시물 상세, 댓글, 멤버·가입 신청 목록, 프로필, 기록자, DM·채팅의 사용자 표시를 보완했다. 서버는 응답 단위로 배지를 일괄 조회하며 프로필 행마다 별도 요청을 보내지 않는다.
- 서버의 새 빈 배지 목록도 우선 적용한다. OFF 후 늦게 도착하는 예전 응답과 계정 전환이 공개 배지를 되살리지 않도록 회귀 검사를 추가했다. 삭제·탈퇴로 가려진 작성자의 배지는 노출하지 않는다.
