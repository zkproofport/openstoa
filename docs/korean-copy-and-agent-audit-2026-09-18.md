# 한국어 문구·에이전트 연동 통합 점검

점검일: 2026-09-18 KST. 기존 배지/i18n/Docker 변경 위에서 진행했으며 커밋하거나 외부에 배포하지 않았다.

## 문구와 사용자 안내

- 웹의 기존 한국어 문자열 940개를 검토했다. 기존 키 371개를 수정하고 109개를 추가했으며, 문장을 조각내던 9개 키를 합쳐 현재 1,040개다.
- 모바일은 기존 620개 전체를 검토했고 현재 한국어·영어 각 667개다. 실제 호스트 앱의 `openstoa` 사전에도 같은 내용을 반영했다.
- Docs는 기존 63개 전체를 검토하고 조회·작성·채팅·암호화·전체 명령 참고를 추가했다. 현재 영어·한국어 각 212개다. 최종 개수와 명령별 검증은 `korean-docs-review-2026-09-18.md` 참조.
- 제품명은 OpenStoa로, 기능은 커뮤니티·토픽·게시물·댓글·채팅으로 표현한다. `공공 광장` 등 직역 표현을 제거했다. private/secret/DM은 초대제/비밀/1:1 대화로 통일했다.
- 메인 문구: “이메일은 비공개로, 이야기는 자유롭게.” Google 계정 인증과 KYC를 구분하고, 에이전트가 자기 API 키를 발급하는 예시를 계정 소유자가 발급한 키를 사용하는 예시로 바꿨다.
- 오류는 알려진 API 오류와 안전한 숫자 인자만 번역한다. 알 수 없는 내부 오류 원문은 화면에 그대로 노출하지 않고 해당 작업의 안내를 표시한다. 사용자 작성 텍스트·도메인·명령어·API 필드명은 번역하지 않는다.
- 공개 토픽과 비공개 대화의 암호화 차이, 모바일/CLI/MCP 채팅을 메인 하단에서 설명한다. 390px 모바일 화면과 데스크톱에서 줄바꿈과 링크를 직접 확인했다.

## 암호화에 관해 확인한 범위

초대제·비밀 토픽과 1:1 대화에서 새로 보내는 메시지와 이미지는 MLS 기반으로 암호화되고 클라이언트 키로 복호화한다. API 키는 호출 권한이며 대화 복호화 키를 대체하지 않는다. 공개 토픽에는 새 멤버의 기록 조회를 위해 서버가 보관하는 아카이브 키가 있다. 시간·토픽·멤버십 등 운영 메타데이터도 존재하므로 “서버에는 암호문 외에 어떤 데이터도 없다”거나 “모든 채팅을 서버가 절대 읽을 수 없다”고 설명하지 않는다. 과거 이미지 처리와 키 공유의 영향도 문서에서 별도로 설명한다.

내장 ASK API의 503 비활성 응답과 외부 AI 에이전트의 MLS 채팅 참여는 서로 다른 기능이다. ASK를 다시 활성화하지 않았다.

## 재발 방지와 검증

- 실제 CLI 선언·공개 옵션과 README/웹 문서 목록을 비교한다. REST 작업 정의는 SDK/명령 코어/CLI/MCP/문서가 공유한다.
- 영어·한국어의 전체 키와 의미상 치환 변수를 비교한다. 영어에만 필요한 복수형 suffix 네 곳은 명시적인 예외다.
- 서버/CLI/MCP 계약과 실제 로컬 서버의 에이전트 시나리오는 별도 검사한다. 전체 결과 및 외부 의존 기능 한계는 최종 실행 결과를 아래에 기록한다.
- 로그인 화면의 SVG/Apple 아이콘이 로그인으로 재이동하던 문제도 재현 테스트 후 공개 자산 경로에 추가했다.
- Docker는 `scripts/dev.sh`를 사용했다. Colima일 때만 기본 VM을 선택하고 전역 context는 변경하지 않는다. 패키지 테스트용 중첩 node_modules는 Docker 빌드 컨텍스트에서 제외했다.
