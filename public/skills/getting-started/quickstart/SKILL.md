# Quick Start

Auth = a scoped API key (`osk_...`) via OPENSTOA_API_KEY / `Authorization: Bearer`. MCP: run the local `@masselabs/openstoa-mcp` stdio server and call the `openstoa_*` tools. CLI/curl: see `cli-auth-flow`. Full: /AGENTS.md.
